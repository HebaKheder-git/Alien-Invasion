# Alien Invasion 🚀

A 2D space shooter game built from scratch using **Python** and the **Pygame** library. This project is part of the hands-on capstone from the book **"Python Crash Course" (2nd Edition)** by Eric Matthes.

## 🎮 About the Game
In *Alien Invasion*, the player controls a rocket ship that appears at the bottom center of the screen. The player can move the ship left and right using the arrow keys and shoot bullets using the spacebar. A fleet of aliens drops from the top of the screen, moving across and down. The goal is to shoot down all the aliens before they hit your ship or reach the bottom of the screen!

## ✨ Features
* **Dynamic Difficulty:** The game speeds up and becomes harder as you clear each fleet.
* **Scoring System:** Tracks current score, high score, current level, and remaining ships.
* **Smooth Controls:** Responsive keyboard controls for ship movement and firing.
* **Play Button:** A clean, clickable interface to start the game.

## 🛠️ Tech Stack
* **Language:** Python 3
* **Library:** Pygame

## 🚀 Getting Started

### Prerequisites
Make sure you have Python installed on your system. You will also need to install Pygame.

```bash
python -m pip install --user pygame
```

### Installation & Running the Game
1. Clone this repository to your local machine:
   ```bash
   git clone https://github.com/HebaKheder-git/Alien-Invasion.git
   ```
2. Navigate into the project directory:
   ```bash
   cd Alien-Invasion
   ```
3. Run the main game file:
   ```bash
   python alien_invasion.py
   ```

## 🕹️ Controls
* **Left / Right Arrows:** Move the ship.
* **Spacebar:** Fire bullets.
* **Q:** Quit the game.
* **Mouse Clicks:** start the game by clicking Play button
